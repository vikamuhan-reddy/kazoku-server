# KAZOKU — Building My Own Infrastructure

KAZOKU is my personal homelab and Linux infrastructure engineering project.

The goal is to build, operate, break, troubleshoot and continuously improve a self-hosted infrastructure environment using Linux and open-source technologies.

Rather than following isolated tutorials, every concept is learned through practical implementation and real-world engineering challenges.

**Focus areas**
- Linux system administration
- Networking and infrastructure security
- Containerization and self-hosting
- Virtualization
- Monitoring and automation
- Backup and disaster recovery
- Linux internals and custom Linux systems

This repository documents the architecture, implementation decisions, experiments, failures, improvements and outcomes throughout the journey.

**Build it. Break it. Understand it. Improve it.**
